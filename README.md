# budget-tracker
### For this week's challenge, I focused entirely on giving my existing Budget Tracker a more polished, professional look using CSS, without changing its core structure or functionality. I picked a warm maroon and blush color palette and applied it consistently across the background, headings, table header, and buttons so the whole app feels cohesive rather than mismatched. To improve readability and hierarchy, I paired two Google Fonts — Poppins for headings and Open Sans for body text, labels, and buttons — which makes the page feel more considered than the default browser styling. I also styled the expense table and the Add Expense form with proper padding, clear borders, alternating row colors, and rounded corners so the information is easier to scan and the inputs feel consistent with each other. Finally, I used the CSS box model deliberately by wrapping the page heading, the form, and the expense table each in their own "card," giving them margin to breathe apart from one another, padding inside so content isn't cramped, and soft borders and shadows to visually separate the different sections of the page.
